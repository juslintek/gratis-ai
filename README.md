# Gratis AI

Optional AI assistance for WordPress. Part of the [Gratis Suite](https://gratis.superglobalsdevelopment.com).

## Principles
- Free core is fully usable without AI
- Bring Your Own Model (BYOM) supported
- Non-invasive admin UI
- Never sends data without explicit consent

## Model Providers (planned)
- OpenAI-compatible endpoint (any provider)
- Local model (Ollama, llama.cpp, LM Studio)
- Hosted model (future managed service)

## Assistants (planned)
- Site health explanations
- Cache recommendations
- Performance tracing analysis
- Backup/restore guidance
- Builder/theme assistance
- Content suggestions

## Monetization
Only hosted model usage has a cost (to cover GPU infrastructure).
Everything else is free.
